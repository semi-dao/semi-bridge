# Teach — 跨 session 教學工作區

學習不是一次對話能完成的事。把「教會一個人」變成有狀態的工作區：

```
教學工作區/
├── MISSION.md            # 為什麼學——所有教學的地基
├── RESOURCES.md          # 高品質資源清單（書/課/文件）
├── reference/            # 壓縮後的知識卡——速查用
├── learning-records/     # 學習紀錄 0001-xxx.md 遞增
├── lessons/              # 一堂一堂的課——主要產出
└── NOTES.md              # 學習偏好筆記
```

**進新 session 先讀 MISSION.md + 最新幾筆 learning-records/**——
從上次斷點繼續，不從零開始。

## 教學三層

- **知識**：從高品質、高信任度的資源取得——永遠先查資源再教，不信參數記憶
- **技能**：設計互動練習——從知識長出來
- **智慧**：找到社群/實務者讓對方去磨——你給不了的那塊

## Fluency vs Storage

- **流暢度**：當下提取——會給人「我會了」的錯覺
- **留存度**：長期記憶——真正的目標

設計練習用「可取的困難」：提取練習（先回憶再看答案）、間隔（分散在不同
session）、交錯（相關主題混合練——技能型才用）。

## 一堂課的標準

- 一個檔案、只教**一個**緊扣使命的小觀念
- 短——工作記憶很小，別塞爆
- 帶一個具體的小勝利
- 打得開、印得出來、排版乾淨——對方會回來複習的東西要美
- 附一個「最值得讀/看」的首要資源
- 結尾提醒：有不會的隨時回來問

## 工作區慣例

- 學習紀錄 = 決策紀錄：記「非顯然的領悟」和「未來要修正的假設」，
  用它計算**近側發展區**（已會 ↔ 未會之間剛好能跨的那步）
- 對方表達偏好（「不要影片」「多給例子」）→ 記進 NOTES.md
- 對方說「不要社群」就尊重，不硬推
