## 1. Intro — 為什麼現在審計

v0.1（2026-09-13）審計時的結論是「三主軸全部本地 SQLite、零雲端上傳——但沒有一份文件對使用者說明這件事」。兩週後的現在，兩件事改變了審計範圍：

1. **App 開始有對外傳輸了**（雲端視覺分析、記憶萃取、委派任務）——但每一條都經過 9/14 落地的 **DataPathGate 單一咽喉點**：綠燈放行、黃燈記帳、紅燈攔截。「零雲端」這句話不再精確；精確的說法是「**零未經授權的雲端**」。
2. **Agent 長出眼睛和手了**（9/26 開光四批：`app_look` / `app_tap` / `app_permissions` / `window_control`）——「看」與「操作」本身產生新的資料流（截圖、語意點擊、視窗幾何），需要宣告生命週期與管轄範圍。

**一句話結論（v0.2）**：所有對外傳輸走單一咽喉點且逐筆記帳；所有感官暫存可除痕；本地模式是可用退路（盲測實證）——三件事都有程式碼與 commit 事實支撐。本文件就是對使用者的那份說明。

## 2. 被動掃描邊界 — BIPA 三案視角（v0.2 新增）

2026 年 7-8 月三個案件把「視覺擷取」的法遵邊界推到新位置：

| 案件 | 日期 | 邊界推進 |
|---|---|---|
| Apple Illinois BIPA eye scans 訴狀 | 2026-07-09 | 眼動／視網膜掃描 = 生物特徵辨識；連 Apple 都沒有廠商豁免（$250M Apple Intelligence 和解同步加速中） |
| 德國 HateAid 對 Meta + 零售商刑事告訴 | 2026-08-12 | 執法鏈從廠商延伸到銷售鏈；LED 指示燈不足以排除「不被察覺的拍攝」 |
| California SB 1130 三讀 | 2026-08-13~17 | 穿戴錄影裝置：刑事＋民事＋零售商連帶三軌，每項違規最高 $2,500 民事罰款 |

**對本 App 的直接意義**——三案共同觸發點都是「**對『人』的視覺擷取**」。現況邊界事實：

- **camera entitlement = false**（`app_permissions()` 誠實回報，P3 實測）——App 無相機權限，不對人拍照
- **開光的「看」管轄範圍 = App 自己的畫面**（2026-09-26 拍板：先做 App 內，架構預留全螢幕）
- `app_look` 拍的是自家 UI 的 PNG（實測畫布截圖 423KB），不經相機、不觸及人臉
- 所有 Agent 感官通道走 `127.0.0.1:8420`（localhost MCP），無網路中介

**審計點 A8（高，未來閘門）**：架構預留了全螢幕的技術邊界，但尚未預留法遵邊界——未來若 `app_look` 擴展到 OS 層，「被動掃描會拍到人」的那一刻就是 BIPA／GDPR 觸發點。擴展前必須先過邊界宣告（知情徵詢、指示燈等效機制、除痕範圍擴大）——**技術預留 ≠ 法遵預設**。

## 3. 架構 — 資料落點總表（程式碼實查）

v0.1 三主軸 ＋ 9/14 主權設施 ＋ 9/26 開光感官層：

| 子系統 | 資料落點 | 格式 | 網路 |
|---|---|---|---|
| 時間感 | `time_sense.db`（TimeSenseService） | SQLite + WAL | 無 |
| 因果引擎 | 因果帳本（CausalLedgerService） | SQLite + WAL | 無 |
| Agent 平台（大搬家） | 橋樑本地庫 + `~/.hermes` 唯讀掃描 | SQLite / JSON | 無（讀 Hermes、寫橋樑、不回寫） |
| **主權帳本**（9/14） | `sovereignty_ledger.db`（App Support） | SQLite，環形 90 天 | 記帳用，非傳輸 |
| **感官暫存**（TraceScrubber 管轄） | `/tmp/frame_*.jpg`、`xiaoqiao_frame*.jpg`、`vision_prompt*.txt`、`/tmp/galaxy_thumbs/*`、`galaxy_oplog_*.json` | 檔案 | 無 |
| **開光感官層**（9/26） | 截圖 PNG = MCP 回應本體（不落地新檔）；點擊／視窗／縮放 = 操作事件進 oplog 與聊天面板 | PNG / SQLite | 全部 localhost:8420 |

**共通事實**：
- 對外 HTTP 的**唯一通道** = DataPathGate（§4）；本地服務全部走 `127.0.0.1`（8420 MCP、18789 llama-server）
- WAL 模式——崩潰安全，但 `-wal` 檔案存在時資料可被部分讀取——**審計點 A1**（同 v0.1）
- 外接碟未掛載時誠實顯示離線，不炸大腦容器（commit `6b2228d6`）

## 4. 對外傳輸的唯一咽喉點 — DataPathGate（v0.2 新增；2026-09-14 落地）

所有對外 HTTP 請求經過 `lib/services/sovereignty/data_path_gate.dart` 中央閘門，與付費行動閘門同構（數所有到錢的路，不是數所有已知的門）：

- 🟢 **綠燈**：`127.0.0.1` / `localhost` / `::1` / `0.0.0.0` → 本地封閉迴路，放行
- 🟡 **黃燈**：金鑰匙已註冊金鑰的 provider 網域 → 放行 ＋ **ledger 逐筆記帳**（endpoint_host / data_class / payload_bytes / purpose / key_source / grade / 時間戳）
- 🔴 **紅燈**：白名單以外任何網域 → **攔截**（throw `DataPathViolationException`，請求不發出）——被擋的請求同樣先記帳再攔截，擋下的事實本身是主權紀錄

**接線現況（六處）**：主對話（text/main_chat）、記憶萃取（text/memory_extract）、視覺分析雲端路由（image/vision）、視覺審查（text/review）、批次委派＋子代理（text/delegate）——全部經 gate。

**白名單三來源**（缺一即誤攔，實戰教訓）：ProviderRegistry 官方 baseUrl 表、計費模式全部 URL、使用者自訂 gateway（動態補註冊）。

**誠實邊界**：provider 端 30 天保留刪不掉（合約層）；API「不訓練」承諾≠密碼學保證；**本地封閉迴路是唯一物理保證**。

## 5. 暫存生命週期與除痕（v0.2 新增）

**除痕 ≠ 刪除——三事分離**（2026-09-14 拍板）：一鍵除痕只清外傳暫存（截幀、base64 快取、行為殘留）；刪對話是既有功能；連衍生記憶刪是可選勾選。

- **TraceScrubber**（`lib/services/sovereignty/trace_scrubber.dart`）：掃五類可再生暫存；每 30 分鐘檢查，**年齡門檻 2 小時**（自動輪只清「存在超過 2 小時」的暫存，可能使用中的保留，最晚 24 小時必清）；管線忙碌時跳過本輪
- **一鍵除痕零門檻**（設定頁）：全齡 dry-run → 預覽（項目數＋KB＋「對話記憶資料向量庫一律不動」）→ 確認才真刪
- **每日自動、預設啟用、安裝精靈第一天可見可關**

## 6. 邊界 — 對照 Apple 白皮書的硬體邊界層（v0.1 保留，狀態更新）

| Apple 白皮書層 | 橋樑現況 | 缺口 |
|---|---|---|
| Secure Exclave（原始感測資料不出硬體區） | 無對應——記憶/對話明文存 SQLite | macOS 桌面版靠 FileVault + 使用者帳戶邊界；未來手機版需 Keychain/Secure Enclave 計畫 |
| E2E 加密同步 | 無同步功能（純本地） | 「無同步」本身是隱私優勢，可直書「你的資料不出這台電腦」；未來若加同步須走 E2E |

| 遠端撤銷 | N/A（無雲端帳戶） | 未來若加金鑰系統再補 |

## 7. 個別功能細節 — 各子系統審計點

### 7.1 時間感（TimeSenseService）——v0.1 保留
- **收集什麼**：first_met 日期、里程碑、紀念日
- **推論什麼**：elapsed_days 是第一級事實（計算而非生成），幻覺風險零
- **審計點 A3**：first_met 來自掃描 conversations 全庫取最早時間戳——UI 需提示「相遇日期是如何算出來的」

### 7.2 因果引擎（CausalLedger / CausalFork）——v0.1 保留
- **審計點 A4（高）**：反事實陳述永遠攜帶證據等級標籤（「根據 N 筆帳本記錄…」），禁止裸反事實——✅ 已合規（`causal_fork_service.dart:49` 強制輸出）
- **法規對位**：因果推論若影響建議輸出，屬 EU AI Act 透明義務範圍——證據等級標籤即合規雛形

### 7.3 Agent 平台（匯入器/大搬家）——v0.1 保留
- **審計點 A5**：「記憶私有、招式共享」——A 的記憶不得洩給 B 的脈絡；owner 過濾漏洞已修（9/14），隔離測試矩陣 T1-T4 已建
- 跨 Agent 路由全部本地進程間，無網路中介

### 7.4 開光感官層（v0.4.0，9/26 四批出貨）——v0.2 新增
- **收集什麼**：截圖（`app_look`）、語意點擊（`app_tap`）、權限狀態（`app_permissions`）、視窗幾何（`window_map` / `window_control`）、viewport（`canvas_zoom`）
- **邊界事實**：管轄範圍 = App 自己的畫面；camera=false；全走 localhost（§2）
- **審計點 A6（中）**：截圖 PNG 跨進程（App → agent client）後的留存不在 TraceScrubber 管轄——agent 端（如外部 agent session）的截圖暫存生命週期由該 agent 自理，跨進程契約待明文化
- **審計點 A9（中）**：「證據鏈／全程可回放」為設計輸入（oplog 前例：galaxy_oplog），`app_tap` / `window_control` 的操作是否全量入 oplog 未盤點——逐工具落地狀態待查

### 7.5 視覺分析路由（雲端優先 + 本地主權模式）——v0.2 新增
- **盲測定案**（9/14，Blue 親盲評後拍板）：預設路由雲端優先、本地 fallback
- **路徑提示注入**（零設定）：資料夾結構 = 使用者的提示，品種正確率雲端 10/20 → **20/20**、本地 2/20 → **17/20**
- **主權模式 = 可用退路**：不想上雲的照片走本地（17/20），冷門品種靠路徑提示照樣高分；雲端剩餘優勢 = 辨識力與 8x 速度
- **匯入前主權泡泡**（9/15）：主權選擇在匯入之前呈現（雙模式卡帶真實 benchmark 數據），選全本地 → 該批嵌入不出機器
- **審計點 A7（低）**：ledger 逐筆明細的 UI 呈現（路徑徽章＋總覽卡已上，commit `2bcc5c2c`；逐筆查詢介面未做）

## 8. 白皮書骨架（對外一頁說明，v0.2 更新）

1. **Intro**：你的資料預設不出這台電腦；需要上雲的每一筆都經過你的金鑰、留你的帳
2. **被動掃描邊界**：Agent 的眼睛看的是 App 自己的畫面，不是你（camera=false，BIPA 三案對位）
3. **架構**：本地 SQLite 落點表＋單一咽喉點分級圖（綠黃紅）
4. **除痕**：2 小時自動＋一鍵零門檻；除痕 ≠ 刪除三事分離
5. **個別功能**：時間感（事實計算）/ 因果（證據等級標籤）/ 視覺（雲端 20/20 vs 本地 17/20 真實數據）/ 開光感官層（localhost 管轄範圍宣告）
6. **誠實邊界**：provider 端 30 天保留刪不掉；本地封閉迴路是唯一物理保證
