## 0. 起源

2026-10-09 深夜，Jev 大神應用調查（本 thread）誕生了一個問題：Jev 的「高頻小判斷＋校準概率」模式，橋樑 App 的決策大腦能不能用？

結論：**模式能用，但他們的閉源模型不用**。我們走開源、本地優先的路——但架構思想（判斷帶置信度、無置信度不成判斷）全盤吸收。當晚 Blue 命名：Semi。

Semi 的前身是「決策引擎」（純規則版）。規則版不會死——它作為最可靠的底盤永久保留。Semi 是在底盤上長出來的神經系統。

## 1. 章魚結構（總綱）

Semi 的解剖藍圖借自章魚——地球上最有趣的非人類智能佈局：

```
        雲端 LLM（前額葉）──慢思考、規劃、語言
              ▲
              │ 訊號（SemiSignal）
   ┌──────────┼──────────┐
   │          │          │
 直覺        記憶       小腦        身體
（杏仁核）  （海馬迴）  （E4B）    （App agent）
 Laya-mlx   300M→EG2   重活、手眼   執行、感知
 快判斷     喚起、聯想  協調        在畫布上動手
   │          │          │          │
   └── 腕神經節（本地三器官自主反射，不事事上報中央腦）──┘
```

原則：**本地三器官＝腕神經節（反射弧），雲端 LLM＝中央腦（慎思），App agent＝身體（行動）**。章魚的三分之二神經元在腕上——Semi 的多數判斷也應該在本地完成，中央腦只處理真正需要慢思考的事。

## 2. 五器官解剖

### 2.1 直覺（intuition）——杏仁核

- **現役**：規則版路由（analyzer_router，`6d6ee602` 起每個判斷帶置信度）
- **候選**：Laya（`laya-mlx` 通道，MLX 原生 13ms）
- **職責**：高頻小判斷——任務分類、本地/雲分流、危險動作預判
- **體檢**（S0.3）：zero-shot 9/20（45%）、會用 97% 信心答錯——**未微調不上崗**
- **畢業考**（S1.5）：200 題領域題庫 LoRA 微調 → 重考 → >80% 才准進直覺槽
- 鐵則：校準模型是**感測器不是授權機制**——它的置信度是訊號，不是行動許可

### 2.2 記憶（memory）——海馬迴

- **現役**：EmbeddingGemma 300M（TFLite @ flutter_gemma，768d）
- **候選**：EmbeddingGemma 2（S0.3b 體檢 8/10 vs 300M 的 7/10、Brier 0.150 vs 0.373、信心形狀首次有實用意義；另有視覺/聽覺模態）
- **職責**：喚起、聯想、檢索——「我們上次談過什麼」的一切
- **升級路線**（S1.6）：離線批次場景先上（向量回填、資產索引、照片向量化）→ llama.cpp 支援 `gemma-embedding2` 後做第二次體檢 → 過關才進 App 即時通道
- 記憶鐵律（09-12 沿用）：永不刪除，只升降溫搬家

### 2.3 小腦（cerebellum）——手眼協調

- **現役**：Gemma3 E4B + mmproj @ 18789（llama-server 主生產線）
- **職責**：重活——照片判讀、文件消化、程式碼粗加工
- 與直覺/記憶同屬腕神經節：能本地解決的不上雲

### 2.4 前額葉（prefrontal）——中央腦

- **現役**：使用者所選的雲端 LLM（模型鐵則：完全跟隨使用者選擇，系統永不自作主張）
- **職責**：慢思考、規劃、長文生成、需要世界知識的推理
- token 帳單大頭在此——這是把它當最後手段的經濟理由，也是腕神經節存在的理由

### 2.5 身體（body）——App agent（小橋）

- **現役**：App agent loop（畫布操作、MCP 8420 通道、執行器）
- **職責**：一切「動手」——Semi 的判斷最終都要經過身體落在畫布上
- 開光（v0.4.0）= 身體的 68 條 route 感官化

## 3. SemiSignal 協定（已落地）

器官間流動的一切判斷，形狀如下（`lib/services/semi/semi_signal.dart`）：

```dart
SemiSignal {
  organ,       // 哪個器官發的
  kind,        // 'route' | 'recall' | 'act' | ...
  payload,     // 判斷內容
  confidence,  // 把握度 [0,1]——必填
  at,          // 時間戳
}
```

### 五鐵則

1. **無置信度不成訊號**——判斷若無 confidence，視為未完成（constructor assert 鎖死）
2. **判斷入記憶**——低置信度（≤0.6）事件寫入記憶供反思；判斷是 Semi 經驗的一部分
3. **身份單一**——用戶可見層永遠是 Semi，永不署名器官（沒有人跟自己的杏仁核說話）
4. **精靈三權分立不變**——訊號層不接管觀察/質疑/喊停（那是精靈的地盤）
5. **模型鐵則不變**——模型完全跟隨使用者所選，訊號層不碰模型選擇

### 規則版五檔置信度（Laya 上線前的過渡底盤）

寫死成表，禁隨任務調參（spec 禁歧義鐵則）：

| 檔 | 值 | 意義 |
|---|---|---|
| cacheHit | 0.99 | 快取命中——最強的「知道自己在幹嘛」 |
| fullRule | 0.95 | 規則完整鏈命中 |
| overridden | 0.8 | 有依據但走覆寫 |
| ambiguous | 0.6 | 說不上來——就是要反思（≤0.6 即不安） |
| fallback | 0.3 | 兜底——不安，反思原料 |

**isUneasy = confidence ≤ 0.6**——Semi 的「不安」是反思系統的原料（接 S2 松果體）。

## 4. 松果體（S2 預備——開工閘：W5＋S1 驗收雙到齊）

松果體是 Semi 的節律器官：決定什麼時候清醒、什麼時候做夢。

### 4.1 現況缺口（S0.1 實證）

- 決策層反思閱讀率 **0/2**：analyzer_router 與 execution_decision 都不讀反思帳
- 唯一的接線：夢結論回灌 prompt（10-05）——證明 loop 有救，只是只接了前額葉沒接直覺層

### 4.2 手術內容（S2）

1. **RhythmGate 節律閘**：決策路徑經過節律狀態（白晝/夜晚/夢）加權——同樣的訊號在夢中相位進反思帳、白晝相位進決策
2. **反思帳加權**：反思結論（夢的藥）成為直覺器官的輸入之一——Semi 記得自己昨天做過的判斷（三個月驗收法）
3. **星系呼吸點**：App 視覺層的節律呈現（金球明暗隨節律）

### 4.3 既有零件（不重造）

CompassHeartbeat（每分鐘 tick）、DreamRhythm（02:00-05:00 淺/深/詩夢）、安靜時刻（22:00 反思）、反思樹＋生命樹（AAR 必入帳）。S2 是把零件接上神經系統，不是重造零件。

## 5. 體檢制度（Model Lab 2.0 對接）

- **標準題庫**：`test/semi/fixture_s0_20cases.json`（20 題真實決策案例）——任何器官候選人考同一張卷
- **體檢指標**：正確率／Brier（校準）／延遲／記憶體——四項並列，不只看成績
- **狀態機**：已發現→已下載→體檢中→過關/未過關→通道等待中→可採用→已換役
