# 大腦圖譜七模式 — 感受指南（使用者 體驗版）

> 教練 Agent 2026-08-20 凌晨 — 給 使用者 明天用。
> 這份不是技術文件，是**每個模式我想讓你看見什麼**的心意。
> 用法：打開大腦圖譜 → 切到模式 → 對照下面問自己那句話 → 看圖有沒有回答你。
> 如果圖沒有回答，就是我的失職——請直接開罵，那是最寶貴的回報。

## 全域共通（先記這五件事，每個模式都用得到）

| 你做的動作 | 會發生什麼 | 我想給你的 |
|---|---|---|
| **滾輪拉遠** | 星系團全貌：集群靠攏程度＝關係強度，只剩粗亮主動脈線 | 「我的大腦由哪幾個星系組成」 |
| **滾輪拉近** | 潛入星系內部：標籤浮現、微血管細線現身 | 「這個星系裡到底有誰」 |
| **滑鼠移到任一點** | 它所屬的整個星系亮起來，有連結的鄰星系微微亮，其他壓暗 | 「這區塊跟誰有關係」 |
| **點擊節點** | 右側完整內容；檔案節點有「開啟檔案」 | 「這到底是什麼」 |
| **雙擊檔案節點** | 直接用系統程式打開那個檔案 | 「立刻看本體」 |

還有：點的大小亮度＝連結多寡（一等星=樞紐記憶，五等星=孤點）；強連結的線會呼吸流動（電流感）；節點可以拖著玩，放手 Q 彈回原位。

## 模式 0：現狀全景 — 「我的大腦現在長什麼樣？」

- **你帶著的問題**：我最近的心力都花在哪裡？整體狀態好嗎？
- **我想讓你看見的線索**：記憶是主角（亮粒子），檔案是配角（青色小點）；哪個星系最大最亮＝你最近的 生活重心；孤立的小暗點＝還沒長出連結的孤單記憶。
- **這如何幫你**：一眼看出失衡——「門（選擇）的星系比焦慮的星系小好多」＝該開門了；「發光時刻比必須時刻少」＝該照顧自己了。
- **誠實現況**：✅ 這模式最完整。背景塵埃（觀察日誌）已降級為紋理，不搶主角。

## 模式 1：能量流向 — 「我的時間往哪裡流？」

- **你帶著的問題**：事情怎麼演變成現在這樣？什麼在推動什麼？
- **我想讓你看見的線索**：時間染色——越舊越冷（深藍）、越新越暖（橘金）；從冷色區循線到暖色區，就是你的能量軌跡。
- **這如何幫你**：回溯脈絡——「原來這個決定是從那條線發展出來的」「我這個月都在響應、都沒有發起」。
- **誠實現況**：⚠️ 半套。時間染色有了，但記憶之間的因果邊（connections 表）還是空的——線畫的是記憶↔檔案的引用。真正的「流向」要等連結生成機制。**看的時候請把重點放在顏色分佈，不是線。**

## 模式 2：選擇路口 — 「我面對過哪些選擇？」

- **你帶著的問題**：哪些門我進了、哪些我錯過了？現在還有門在等嗎？
- **我想讓你看見的線索**：門的星系應該置中發光（金色光環），其他房間退到外圍。19 條門記錄：邀請出現的、進入的、錯過的、還在等的。
- **這如何幫你**：看見自己的選擇模式——「我總是錯過邀請型的門」是行為模式的鏡子。
- **誠實現況**：❌ 跳票中。實際上門常被檔案星系擠到邊緣，四種門狀態（邀請/進入/錯過/等待）也還沒有色碼分化。**這是七模式裡我欠你最多的。**

## 模式 3：慣性擺動 — 「什麼在拉扯我？」

- **你帶著的問題**：我的焦慮、比較、「必須」來自哪裡？
- **我想讓你看見的線索**：擺錘星系在搖擺（動畫），把無形的慣性具象成看得到的拉力。
- **這如何幫你**：「原來我這週的焦慮都連到同一個比較目標」——看清楚就能放下。
- **誠實現況**：⚠️ 半套。搖擺動畫有了，但只有 5 條擺錘記憶、幅度還沒按拉力強度分化。樣本太少，星系很小——這反映的是「擺錘還沒被認真記錄」，不是圖譜的錯。

## 模式 4：跨島聯想 — 「哪些記憶之間有奇蹟連結？」

- **你帶著的問題**：不同領域的記憶有沒有暗中相連？我的直覺跳躍有根據嗎？
- **我想讓你看見的線索**：跨星系的虛線橋——「農場學的東西原來跟產品決策同構」。
- **這如何幫你**：這是創造力的視覺化。直覺不是幻覺，是還沒被畫出來的邊。
- **誠實現況**：❌ 空的。跨島虛線的渲染準備好了，但跨房間的連結資料是 0。向量庫裡 34060 條嵌入是現成燃料，只差把「跨房間+相似度高」算成邊。**七模式裡投資報酬率最高的未兌現支票。**

## 模式 5：成長軌跡 — 「我走了多遠？」

- **你帶著的問題**：重要時刻怎麼累積成今天的我？
- **我想讓你看見的線索**：水平時間軸，重要記憶（importance≥3）從左（舊）到右（新），弧線串連，峰值時刻有星星光環。
- **這如何幫你**：低谷時回看——「三個月前我連 X 都不會，現在已經 Y」。這是給未來的你的證據。
- **誠實現況**：⚠️ 半套。時間軸有了但**沒有日期刻度**（看不見時間的時間軸）；右段的大片空白是誠實的——記憶進料不穩定，某些日子斷糧。橫向很長，記得平移探索。

## 模式 6：資產地圖 — 「我擁有哪些知識檔案？」

- **你帶著的問題**：我的檔案怎麼跟記憶關聯？東西放哪了？
- **我想讓你看見的線索**：記憶（亮粒子）＋檔案（青色粒子）＋兩者之間的微細引用線；晨間拾穗、農場照片、鹿角蕨、IG 素材都在這裡有座位（公平配額制，備份碟吃不掉農場的席位）。
- **這如何幫你**：「這個概念我有哪些檔案支撐」＋雙擊直接開檔。人類的痕跡跟 agent 的痕跡同框。
- **誠實現況**：✅✅ 這模式剛大手術完：公平配額載入、存在過濾、雙擊開檔都通了。**641 個節點，人類資產回家了。**
