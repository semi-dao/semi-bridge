# Spec: 無限插槽系統（Infinite Slot System）

> 日期：2026-10-04 ｜ 狀態：待 Blue 批准
> 來源：Discord #閒聊 thread 1556176792094769224 grill-me 完整走查（Q1–Q11 全數拍板）

## 為什麼要做

使用者在 GitHub 上看到任何想用的開源程式，都能讓它住進橋樑 App 的一個獨立插槽裡運行——插槽跑得再兇、甚至崩潰，主程式照常活著。「安裝開源程式」從技術操作變成一次人機對話（grill-me 流水線）。北極星是「任何」，v1 承諾「分層、可驗證、可升級」。

## 使用者故事

- 身為使用者，我在任何對話入口貼一個 GitHub 連結，agent 就主動接手跟我聊怎麼用它
- 身為使用者，插槽跑暴了，App 自己先斷電再通知我，不用我救火
- 身為使用者，我幫插槽取了名字，之後跟 agent 講這個名字他就知道是哪個

## 架構設計

### 執行分層（邊界後面的引擎可換檔，骨架不變）

```
Tier 1  純網頁/HTML 工具        → WebView sandbox          ✅ v1
Tier 2  WASM/WASI 程式          → WASM 沙箱（能力制）        ✅ v1 目標
Tier 3  CLI 工具（ffmpeg 等）    → 獨立 process + OS 沙箱    ⚠️ 視進度
Tier 4  任意原生碼 / GUI app     → 輕量 VM                  🔮 未來
```

插槽與主程式只靠一條訊息通道（JSON-RPC，同 MCP 8420 模式複用）。能力制權限 deny-by-default：插槽要網路/檔案，逐項由使用者授予。

### 安裝流水線（核心使用者體驗）

```
貼 GitHub 連結（任一入口）
  → 全域懸浮對話窗自動彈出
  → App agent 開 grill-me：白話聊「這程式是什麼、你想怎麼用、要什麼權限」
  → 權限拍板：綠燈自動過；黃燈/紅燈 → GlobalNoticeChannel 走全域對話點頭
  → agent 動手安裝 + 親自測試（紅隊式：試著攻它）
  → 交付測試報告（能跑什麼、攻擊擋住/沒擋住、資源佔用）
  → 裝不動 → 紅字誠實回報原因，絕不假成功（UI 誠實鐵則）
  → 經驗計入生命樹 + 羅盤長新規則（下次同類程式直接變聰明）
```

### 入口（四條，全走同一流水線）

1. 全域對話（快速鍵呼出懸浮窗）貼連結
2. 對話頁面的對話框貼連結
3. 畫布頁面的對話框貼連結
4. 首頁卡片區「插槽」卡（位置：社群卡旁邊）→ 插槽管理頁 →「+ 新增插槽」

### 插槽管理頁（UI 定案 2026-10-06，模擬圖 v2 已過 Blue 目）

定案圖：`design-mockup/slot-management-mockup-v1.html`（截圖存證 `Blue資料區/slot-mockup-v2.png`）

- **首頁「插槽」卡**：即時統計（N 運行中・M 已停用）＋「進入管理」按鈕；空狀態為教學式（「貼上一個 GitHub 連結，讓開源程式住進來」＋範例按鈕）（Q-B:a 拍板）
- **卡片式分類**：同類插槽（如 skill、CLI 工具）歸進同一張大卡，大卡標題=類名+數量+一句話說明（grill-me 萃取）；點大卡展開該類的每個插槽小卡。分類**自動歸檔為主，小卡上有「⇄搬家」按鈕手動改**（Q-A:c 拍板；搬家=按鈕式選目標分類，非拖放）
- **小卡**：使用者取的名字（大字）＋來源 repo（小字）＋認證徽章（Reggie 認證✓/未認證）＋狀態燈（運行/停用）＋權限圖示（🌐網路 🔓檔案）＋記憶體用量
- **小卡操作按鈕（橫向單行、nowrap、不折行——2026-10-06 Blue 抓包修法定案）**：啟用/停用/更新/⇄搬家/卸載
- **「+新增插槽」**：先出小表單（貼 GitHub 連結）→ 送出才開懸浮對話 grill-me（Q-C:b 拍板）
- **「更新」按鈕**只出現在未認證＋有新版的插槽；認證插槽自動更新不佔按鈕（Q5 拍板）
- **卸載流程**：先問「產生的資料要留要刪」，預設留（Q6:b 拍板）
- 分類是活的：第一批「類」由前幾個插槽安裝時的 grill-me 結果動態長出，跟羅盤一樣會學
- **第一支示範插槽（2026-10-06 Blue 授權小葵挑選）**：`code4fukui/exif-viewer`（MIT、單一 index.html、純客戶端 JPEG EXIF 檢視器）。入選理由：① Tier 1 純網頁最安全 ② 有實質 grill-me 內容——形態討論（獨立畫面 vs 畫布節點）、權限討論（檔案拖放、零網路上傳的隱私故事） ③ 紅隊測試有真戲——驗證網路隔離（真的零外傳？）、怪檔案邊界 ④ 跟數位資產 `圖片/` 資料夾形成天然工作流（照片進 vault → 分享前查/清 EXIF） ⑤ 不複雜：零建置、零依賴安裝

### 運行治理

- **資源看門狗**：單插槽 CPU/記憶體上限；超過 → **自動暫停該插槽 + 通知**（先斷電再報告）。16GB RAM 現實約束寫死在設計裡
- **版本**：認證插槽自動更新；未認證的經使用者同意後 agent 動手更新＋測試，**出問題可回滾原版**（保留前一版）
- **agent 可操作插槽**：插槽是 agent 的手（「幫我用插槽1轉檔這批照片」→ agent 下指令、收結果）
- **插槽最終形態由 grill-me 結果決定**：可以是畫布節點、獨立畫面、終端——管理頁清單是必有的基本盤

### 資料與信任

- **插槽資料位置（2026-10-06 Blue 拍板）**：`~/Library/Application Support/farm.semiwasabi.bridgeApp/slots/<slot_id>/`——跟 App 資料同層，受 `BRIDGE_APP_HOME` 環境變數覆寫（測試不污染）
- **vault 邊界鐵律（2026-10-06 Blue 釐清）**：向量資料庫＝使用者各自匯入的資料夾集合（來自各種位置，`folder_root` 各自獨立）。整理方式是**只讀不動原檔**（只整理、不動檔案）。**agent 只碰向量資料庫界內的檔案，絕不動界外任何檔案**——使用者要 agent 作業的檔案必須先加入向量資料庫（隱私界線）；任務缺檔案時 agent 可建議使用者加入，但不自己伸手
- **數位資產虛擬歸屬（2026-10-06 Blue 補充定案）**：vault 左側資料夾選單**常駐預設數位資產分類**：`圖片/`、`影片/`、`文檔/`、`音檔/`…（未匯入任何資料夾時選單也有這些預設節點）。**App 未來產生的所有數位資產，無論實際存在哪個資料夾，在向量資料庫一律自動歸屬預設分類**（依檔案類型對應：image→圖片、video→影片、doc/pdf→文檔、audio→音檔…）——虛擬歸屬，非實體搬檔；資產實體位置不變（尊重只整理不動檔案原則），vault 檢視層自動掛到預設分類下閱覽
- 插槽產生的資料存插槽專屬資料夾；卸載時問使用者留/刪（預設不刪）
- 供應鏈風險：未認證來源明確標示；認證走 Reggie（`registry.semidao.net`）
- 許願池：未認證插槽裝完測完後，**問使用者**要不要貢獻這筆紀錄上拋；「開源社群市集」整題另開任務，不在本 spec

## 邊界情況

- repo 需現場編譯/缺依賴 → 紅字「裝不動＋原因」，可建議替代
- 插槽裝的版本被 repo 上游刪除 → 凍結本地版繼續用，通知
- 使用者在 grill-me 中聊到一半關掉懸浮窗 → 進度保留，下次打開接續
- 記憶體緊張時新增插槽 → 看門狗先評估餘量，不足就勸退（不硬裝）

| # | 內容 | 驗收 |
|---|---|---|
| C1 | 懸浮窗等級全域對話（QuickAssistant 升級為系統級懸浮窗＋快速鍵，不限場景） | 快速鍵在任何頁面/主視窗外呼出；黑底無邊框白字黑陰影規格 |
| C2 | 插槽資料模型 + 插槽管理頁骨架（首頁「插槽」卡 + 分類卡片清單） | 卡片出現在社群卡旁；新增/啟用/停用/取名/卸載（含資料去留提問）可操作 |
| C3 | Tier 1 執行引擎（WebView sandbox）+ 生命週期管理 | 貼 HTML 工具連結 → 完整流水線跑通（grill-me→權限→安裝→測試報告） |
| C4 | 權限系統接 DataPathGate（綠放行/黃紅全域對話點頭）+ 資源看門狗（自動暫停+通知） | 黃燈權限必經點頭；偽造暴食插槽被自動暫停 |
| C5 | agent 操作插槽（下指令收結果）+ 版本更新/回滾 | 對話指令驅動插槽；未認證更新經同意且可回滾 |
| C6 | 經驗回流生命樹/羅盤 + 測試報告正式化（紅隊章節） | 裝第二個同類插槽時 agent 明顯變聰明（引用前次經驗） |
| C7 | Tier 2 WASM 引擎（能力制沙箱） | WASM 工具跑通且無授權資源不可達 |

## 完成標準

- [ ] 四個入口貼 GitHub 連結都能觸發流水線
- [ ] 懸浮窗等級全域對話快速鍵呼出，不限場景
- [ ] 黃/紅權限未經人點頭，插槽拿不到對應能力（有回歸測試鎖死）
- [ ] 插槽暴食被自動暫停且主程式不死（含本地模型在跑時）
- [ ] 卸載必問資料去留；預設不刪
- [ ] 裝不動必紅字，零假成功
- [ ] 測試報告含紅隊攻擊章節
- [ ] 生命樹/羅盤有插槽經驗新規則可查
