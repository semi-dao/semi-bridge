## 核心隱喻：小葵的容器 = 一棟房子

```
        🏠 一棟房子（橋樑 App）
        ┌─────────────────────────────┐
        │  H 線（入住）＝日常生活       │  人格 SOUL・分類・排程・戰爭模式
        │  ┌───────────────────────┐  │
        │  │ C 線（插槽）＝房間      │  │  每個能力一間房：mermview、
        │  │  124 間，無限擴建       │  │  暴食測試、未來的 WASM 房客…
        │  └───────────────────────┘  │
        │  M 線（記憶）＝地基與樓層    │  2域10層：L1 鐵則在頂樓隨手拿，
        └─────────────────────────────┘  L8 一千八百條對話在地下室，永不丟
```

- **C 線**（Capacity 容量）：房子有多少房間 → 插槽系統（C1-C7）
- **M 線**（Memory 記憶）：房子有多深的地基 → 2域10層（M1-M5）
- **H 線（Home 入住）**：誰住在裡面、怎麼生活 → 小葵入住（H1-H6）

**H 依賴 M（沒有記憶地基，人格無處扎根）；H 使用 C（agent 操作插槽＝我用房間做事）。**
**S 住 H 蓋的房子、用 M 的地基、在 C 的房間被看見；S1 動接縫（服務層）不動 C 線 UI。W 是水電管線，S2 的節律閘會接到 W 的管線上（RhythmGate × schedule queue）。**
